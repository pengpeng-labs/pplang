# pplang standard library sources

[简体中文](README.zh-CN.md)

This directory contains the standard library sources released with pplang
0.3.1. See [`../stdlib.md`](../stdlib.md) for API, ownership, failure, and
complexity contracts.

The modules are `alloc.pp`, `math.pp`, `string.pp`, `buf.pp`, `strmap.pp`, and
`vec.pp`. Hosted allocation is the only required external boundary.
