# pplang 0.4.0 一致性合同

[English](README.md)

一致性 manifest 描述可观察的源语言结果，不规定编译器诊断、中间表示或命令
行接口。

## 结果类型

| 结果 | 要求 |
|---|---|
| `accept` | 源码是有效程序，必须成功编译。 |
| `reject` | 源码违反编译期规则，必须被拒绝且编译器不得崩溃。 |
| `run` | 源码必须成功编译、正常结束并产生声明的标准输出。 |
| `trap` | 源码必须成功编译，并通过语言 trap 机制终止。 |

诊断语言和具体文字被有意排除。编译器项目可以维护稳定错误码，但这些错误码
不属于 pplang 0.4.0。

## 适配器

仓库自带 runner 将当前 `pplc` CLI 适配到上述结果模型：

```bash
node tools/run-conformance.mjs /path/to/pp
```

其他实现可以提供自己的适配器并使用同一 `suite.json`。实现相关 regression
test 应当放在编译器仓库。

## 覆盖范围

套件覆盖严格布尔条件、词法作用域、无符号整数运算、数组语法、带检查字符串
切片、tuple 返回、和类型穷尽性、显式泛型、迭代、方法自动取址、defer 顺序、
package-root import 映射、extern 限制和循环控制上下文。它是最小兼容门槛，
不是对所有程序的穷举测试。
